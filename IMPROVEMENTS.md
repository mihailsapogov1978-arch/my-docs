## 📋 Что нужно сделать пользователю

### 1. Настроить переменные окружения
```bash
cp .env.example .env
nano .env  # или любой другой редактор
```

Заполните `.env`:
```
HELP_USERNAME=ваш_email@yanao.ru
HELP_PASSWORD=ваш_пароль
ZAKUPKI_INN=8901038364
```

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Запустить скрипты
```bash
python get_tickets.py      # Выгрузка заявок
python get_contracts.py    # Выгрузка контрактов
python parse_contracts.py  # Генерация сводной таблицы
```
