# FEAT-011. Электронные авансовые отчёты

## Проблема (Зачем)
До внедрения авансовые отчёты оформлялись на бумаге, что увеличивало
трудозатраты и затрудняло хранение и поиск.

## Решение (Что сделано)
С января 2023 года внедрены электронные формы авансовых отчётов.
Учреждение — одно из первых среди централизованных бухгалтерий
субъектов РФ, внедривших данный функционал в соответствии
с требованиями Минфина России.

## Результат
- Минимизирован бумажный документооборот
- Ускорена обработка авансовых отчётов
